# DobroDesk mobile SDK

This repository distributes the proprietary DobroDesk mobile SDK for native
iOS and Android applications and Flutter, React Native, NativeScript and
Capacitor integrations.

It contains release indexes, publishing workflows and the files distributed
in installable packages. The native SDK engine and UI implementation are
maintained in a separate private repository. Native binaries are delivered
through versioned GitHub Release assets, with SHA-256 checksums.

The first mobile SDK release is being verified. No mobile package or binary
release is available from this repository yet. Registry publishing workflows
remain disabled until package ownership and trusted publishers are configured.

The SDK is proprietary. Public availability of distribution files does not
grant an open-source license. See [LICENSE](LICENSE) for integration and
embedded application distribution rights. Third-party components retain
their respective licenses.
